API Keys

          
Issue keys so external teams can call any agent directly from their CI pipelines, Jira automations, or internal tools — no UI login required.

        


        
        

          
How to call any agent

          
curl -X POST https://your-domain/api/v1/agents/code \
  -H "X-API-Key: lmsdlc_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "github_pr_url": "https://github.com/owner/repo/pull/88",
    "project_name": "My Project",
    "post_back": true
  }'

          

            Every response includes X-RateLimit-Limit-Minute, X-RateLimit-Remaining-Minute,
            X-RateLimit-Limit-Day and X-RateLimit-Remaining-Day headers.
            Exceeding a key's quota returns 429 with a Retry-After header.
          

          

            Bring your own LLM: teams can route calls through their own Anthropic or
            OpenAI-compatible credentials via PUT /api/v1/llm-config (X-API-Key auth), or
            override a single call with llm_provider / llm_api_key /
            llm_base_url / llm_model fields on any agent request.
